# Практическая работа 3–4

Типы данных, арифметика и корректный расчёт показателей.
Программа считает стоимость заказа: база → скидка (%) → НДС (после скидки) → итог
(+ плата за обработку по варианту 3).

## Запуск (IntelliJ IDEA)
- `src/pr34/OrderCalculator.java` — правый клик → Run (ввод с клавиатуры, дробные числа через точку).
- `src/pr34/SelfCheck.java` — правый клик → Run (15 проверок, в конце «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ»).

## Структура
- `src/pr34/OrderCalculator.java` — проверка ввода и расчёт.
- `src/pr34/SelfCheck.java` — граничные проверки и проверка варианта 3.
- `docs/` — Activity-диаграмма и диаграмма классов.
- `DECISIONS.md` — два принципиальных решения.
- `report/` — отчёт (рабочая тетрадь) в формате .docx.
