# Практическая работа 5

Строки, массивы, циклы и методы обработки данных.

Программа разбирает строку табеля одного сотрудника за рабочую неделю («8;9;7;10;8» — часы за 5 дней), проверяет её и считает: сумму часов, среднее в день, количество дней с переработкой и недельную переработку.

## Правила
- Строка содержит ровно 5 значений через `;`, каждое — целое число от 0 до 16.
- День с переработкой — больше 8 часов.
- Недельная переработка = max(0, сумма − 20). Вариант 3: недельная норма 20 (в тексте правил было 40).
- Ошибка одного значения делает весь табель некорректным, сообщение указывает позицию.

## Файлы
- `TimesheetAnalyzer.java` — разбор строки (`parseHours`) и расчёты (`total`, `average`, `overtimeDays`, `weeklyOvertime`, `analyze`). Правила вынесены в константы в начале класса.
- `SelfCheck.java` — проверки: границы 0 и 16, значение 17, пустая строка, неверный формат, число значений, вариант 3.

## Запуск (IntelliJ IDEA)
- `TimesheetAnalyzer` — правый клик → Run, ввести строку, например `9;8;7;10;8`.
  Результат: сумма 42 ч; среднее 8,40 ч/день; дней с переработкой 2; недельная переработка 22 ч.
- `SelfCheck` — правый клик → Run. В конце: «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ».
